# mascota-vue

Proyecto desarrollado en Vue 3 con Vite para practicar el uso de datos dinámicos en un componente.

## Descripción

Esta aplicación muestra una tarjeta de una mascota ideal utilizando un objeto `mascota` dentro de `data()`.

El proyecto permite visualizar:

- Nombre de la mascota
- Tipo de mascota
- Edad
- Estado de vacunación
- Imagen dinámica
- Listado de características

## Tecnologías utilizadas

- Vue 3
- Vite
- HTML
- CSS
- JavaScript

## Funcionalidades aplicadas

En este ejercicio se utilizaron los siguuientes conceptos de Vue:

- Interpolación con `{{}}`
- Objeto dentro de `data()`
- Atributo dinámico con `:src`
- Renderización de listas con `v-for` y `v-else`
- Uso de `:key`

### Instalación del proyecto

```

```
